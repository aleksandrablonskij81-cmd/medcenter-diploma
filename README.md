# МедЦентр «Диагностика+»

Дипломный проект — сайт для компании медицинской диагностики на Django.

## О проекте

Сайт медицинского центра с публичными страницами, личным кабинетом пациента и админкой для управления контентом.

### Функционал

- **Публичные страницы**: главная, «О компании», услуги (список + детально), контакты
- **Форма обратной связи** на главной и в контактах (сохранение заявок в БД)
- **Личный кабинет**: регистрация, авторизация, запись на приём, история записей, результаты диагностики
- **Админка**: управление пользователями, услугами, врачами, записями, заявками, настройками сайта и контентом

## Стек

- **Backend**: Python 3.12, Django 4.2
- **БД**: PostgreSQL 16
- **Фронтенд**: Bootstrap 5 (CDN), Django Templates
- **Контейнеризация**: Docker, Docker Compose
- **Тесты**: pytest, pytest-django, pytest-cov (покрытие 95%)
- **Линтер**: ruff (PEP8)
